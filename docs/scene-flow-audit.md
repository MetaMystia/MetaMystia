# 场景流转审计

Release 4.4.0e

蓝色 **【同步】** 标出模组协调的位置；红色 **【断开】** 路径先主动断开，再执行原游戏操作。常规营业与最终试炼已按此接入连接阶段管理，具体见[连接架构](connection-architecture.md)；已做源码审计与离线验证，未做游戏实测。

- **自由阶段**：主菜单与自由白天允许入房；各自读档、往返主菜单均保留连接。进入意向尚未确认时可以撤回；确认后，结束白天事件与选店也属于共同流程，不能只看 `DayScene` 判断。
- **日期独立**：不要求同一天、同一存档或相同剧情进度。白天换档仅清除本人旧意向、就绪与场景任务；共同推进检查阶段和目的地兼容性，不比较日期。
- **返回与加载**：正常结算、试炼返回不等于读档中断。先回白天的玩家可以自由活动、读档；其他成员收尾期间不开始下一次共同推进。加载期间保留连接，本人未就绪时不能参加开局。
- **同步与清理**：沿用有序消息和明确的阶段确认；离开阶段前停止旧操作，并完成或取消未完成任务。不新增统一的房间玩法轮次。
- **主动断开**：在读档、回菜单、回退等入口重置游戏状态之前执行。客人断开只移除本人；局域网房主断开关闭本地服务器，独立服务器房主断开解散房间，其他成员保留世界连接。
