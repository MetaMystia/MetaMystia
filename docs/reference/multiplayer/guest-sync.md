# 顾客同步

主机运行原版顾客逻辑，在原版收口处探测变化并广播；客机截住自主决定，按主机事件重放原版入口。玩家操作在本地立即生效并上报，不等待主机回复；评价例外，由主机给出最终结果。代码位于 `src/MetaMystia.Mod/Multiplayer/Guests/` 与 `Multiplayer/Messages/WorkScene/Guest/`。

## 登记表与模式

`GuestRegistry` 存于 `Scopes.Scene`，按 `RuntimeId` 和控制器地址索引 `GuestRecord`，离开场景整体失效。Hook 开头取 `GuestRegistry.Mode(controller)`：

| 模式 | 条件 | Hook 行为 |
|---|---|---|
| `Vanilla` | 无联机同伴，或未登记 | 原版 |
| `Scripted` | 剧情创建、由专属同步管理的顾客（幽幽子本体） | 原版，由专属同步处理 |
| `Host` | 主机上的复制顾客 | 原版，并在收口处广播 |
| `Client` | 客机上的复制顾客 | 只放行重放、本人操作 |

只有主机在剧情外经 `PostInitializeGuestGroup` 生成的顾客登记为复制顾客。剧情中生成的顾客和灵梦保护不登记，两端各按原版运行。客机不自行生成顾客。

## 主机收口

| 变化 | 收口 | 消息 |
|---|---|---|
| 生成 | `PostInitializeGuestGroup` 入口 | `GuestSpawn` |
| 入座（生成即入座、出队） | `TrySendToSeat` 成功 | `GuestSeat` |
| 排队 | `MoveToQueue` 之后 | `MoveToQueue` |
| 点单 | 内部订单生成之后 | `GenerateOrder`：订单序号、点单人、点单后资金与剩余点单数 |
| 评价 | 评价台词显示时（彩蛋与改判回调之后） | `EvaluateOrder`：菜酒与最终结果 |
| 离桌 | `LeaveFromDesk` 入口 | `GuestLeave`，原因 `Desk`、`PatientDepleted`、`Repel` 由先前入口标记 |
| 未入座离开 | `MoveToSpawn`、`FlyToSpawn` 入口 | `GuestLeave`（`Unseated`） |
| 数值 | 每帧比较 | `GuestStats`：心情、资金、剩余点单数、耐心与上限、连击计数 |

收口不区分来源，玩家、符卡、事件和打烊产生的同类变化走同一条消息。

## 客机应用

主机事件进入该顾客的待应用队列，只在消息接收和每帧 Tick 时处理，不在原版 Hook 内处理。剧情期间只暂存，剧情结束后处理。

| 情况 | 处理 |
|---|---|
| 本地入座途中、吃饭中、桌位仍被占用、队列已满 | 等待约 1.5 秒游戏时间，期满后补做到座、清理占桌的同步顾客、不入队，再应用；本端剧情顾客占桌时继续等待 |
| 主机判定离开 | 清空该顾客的待应用事件，重放原版离场 |
| 本地没有该顾客或缺前置事件 | 请求快照（`GuestQuery` → `GuestSnapshot`），丢弃待应用事件，按快照阶段直接生成、入队或入座，补上当前订单与已上菜 |

点单与评价在客机上重放原版入口：点单时内部订单生成回填主机结果；评价时在计算出口、台词和评价后续处理入口换成主机结果。续单与离场由主机决定，客机的 `MainOrderCycle`、自主离桌和耐心耗尽离场被截住。资金、小费、经验、热情和连击只在主机改动。

## 玩家操作

赶客：客机本地执行原版 `PlayerRepell`，按本端 buff 记下分支（普通、计次免罚、琪斯美），实际离桌时上报分支与心情，此后忽略该顾客的主机事件。主机执行有房间效果的部分（热情、连击、付款、排队客耐心），不重判 buff；顾客已离开或正在评价时忽略。

上菜：放入、取消和确认在本地立即生效并上报，主机立即裁定，接受则广播，拒绝则只回复操作者。物品归属按端记录：本端放入的为待定，确认后为已确认；顾客离开或面板被强制关闭时退回待定物品，主机拒绝时退回对应物品，被他人替换、取消或确认的视为已转交。外部关闭面板只退回并撤回本端放入的物品；原版此处只退回料理槽，已一并修正。

## 断线

断线结束场景作用域时，仍在场的复制顾客交还原版：未入座的离开，已到座未点单的延迟首单，吃完的补上续单判定，等待离场的离桌；入座途中、排队中、吃饭中的顾客由各自回调按原版继续。

## 未处理

- 同桌两人同时取消或确认造成的复制。
- 冲突按菜品内容比较，同样两份无法区分。
- 符卡对顾客的效果只经收口同步，客机上符卡自行调用的驱逐被截住；符卡分支决定未接入。
