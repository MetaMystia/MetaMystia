# 设定调研与原版测量

阅读限制见 [README.md](README.md)。

## 设定调研

按来源分四层整理，每条写清出处。越靠前越是硬约束，越靠后越是可选的表现手段。

| 层 | 含义 | 在地图中的作用 |
|---|---|---|
| 零设 | 原型：民俗、宗教、历史、文学 | 提供造型母题；可以发挥，但不能和一设冲突 |
| 一设 | ZUN 原作：游戏、设定集、书籍、访谈 | 硬约束：地理关系、景物、角色的活动范围 |
| 二设 | 同人社区通行的形象与梗 | 点缀：玩家熟悉、能会心一笑；控制数量，不覆盖一设 |
| 夜雀食堂 | 本作已有的地图、伙伴说明、台词、卡牌、成就 | 衔接：让新地图和原版世界连在一起 |

### 查找方法

- **一设**：THBWiki 的地点条目与 `东方求闻史纪/<地点>/中日对照` 子页；角色设定查 `附带文档:<作品>/Omake`；游戏对话查 `游戏对话:<作品>/<角色>/中日对照`；曲目注释查 `<作品>/Music`；访谈查 `东方外来韦编/<期号>/…`。
  - THBWiki 的网页入口对脚本请求返回 468 挑战页；MediaWiki API 可以直接读源码：`api.php?action=parse&page=<标题>&prop=wikitext&format=json`，搜索标题用 `action=query&list=search`。请求间隔 1 秒以上。
  - 符卡名、角色称号等写在模板里，源码里只有模板调用；用 `action=parse&text={{<模板>|…}}&contentmodel=wikitext` 让 API 展开。
- **零设**：日文维基等百科中与该地点直接相关的条目（API 同上：`ja.wikipedia.org/w/api.php`），只取能落到地图上的母题。
- **二设**：THBWiki 角色的“二次设定”子页（含代表作品）、常见组合与梗。
- **夜雀食堂**：在逆向仓库和资料站数据里按地名、角色名、技能名搜索（伙伴说明与技能、稀客台词与标签、Roguelike 卡牌枚举、成就文本、装饰与收集品说明）。

### 证据要求

- **引原文**：每条设定摘录原文。日文作品引日文原文，并附中文译文（THBWiki 中日对照或自译，注明）；夜雀食堂引游戏中文文本。只给出处不给原文的条目不算证据。
- **分清来源级别**：
  - 原文：作品正文、设定文档、游戏对话、曲目注释、访谈。
  - 资料站整理：THBWiki 的“相关设定”“设定点”等概括性文字，以及看图描述。可以作为线索，要尽量追到原文；追不到时注明“资料站整理”。
  - 本图推断、本图设计：原文没说、由我们推出来或自己安排的内容，单独列出。
- **记冲突**：不同作品说法不一致时并列原文，不替原作下结论；翻译与原文有出入时以原文为准。
- **记没找到的**：查过但没找到出处的说法（常见二设、看似设定的通俗印象）也要写明“未找到出处”，避免以后被当成设定。
- **留存**：抓取的源码放在不提交的本地目录，文档里写页面标题和链接，方便复查。

## 原版测量

目的：新地图的尺寸、配色、分层、碰撞与坡度画法与原版一致。原版资源只用来测量和对比，不复用。

### 渲染

用 `render_ref.py` 渲染编辑器导出的全白天地图镜像包：

```text
python tools/day-map-art/render_ref.py <镜像包目录> <输出目录> 12                       # 总览，12 像素/格
python tools/day-map-art/render_ref.py <镜像包目录> <输出目录> 48 BeastForest --crop=-42,-30,-14,-6   # 1:1 裁切
python tools/day-map-art/render_ref.py <镜像包目录> <输出目录> 12 BeastForest --debug    # 叠加碰撞与坡度
```

- 镜像包的切片多为图集里的打包精灵：位置以网格顶点和 UV 为准，渲染器对每个精灵拟合一个 UV→局部坐标的仿射变换；`rect` 不是图集坐标。
- 特殊材质（阴影、光照）默认不画，`--fx` 用乘法和滤色近似；它们只是近似，不是材质效果。
- 再从 1:1 图里取小块，按整数倍放大 3–4 倍逐像素看。

### 读规格

| 项 | 原版数据 |
|---|---|
| 网格 | 1 格 = 1 世界单位；地面切片 48×48、PPU 48、pivot (0,0) |
| 地面来源 | 整张手绘后切成 48×48 格，切片名形如 `BeastForest_Seg4_245`，相同格去重；不是可复用的瓦片集 |
| 角色 | 像素帧 64×64、PPU 48，Q 版人物约 1 格高 |
| 相机 | 正交半高 7.5，一屏约 26.7×15 格 |
| 排序层 | 地面 `Background`（约 -3000 ~ -500），阴影 `Background/-1300`；物件 `Character` 按 Y 排序；树冠等 `Overlay/0`；光照 `Overlay/400~700` |

### 读碰撞与坡度

`--debug` 叠加原生碰撞（实心红、触发黄、相机青）和 HEIGHT_MAP 坡度（从高度图像素解码：红通道为大小，绿通道为正负）。

- 可走区域多用一整条多边形轮廓圈出，树干、石块、建筑再单独加小碰撞；相机多边形比可走区域略大。
- 坡度只出现在斜向路径：斜阶梯、斜坡（0.33、0.5、0.66）；拱桥左半 +0.5、右半 −0.5。

### 记录画法

把观察写成可执行的规则（描边颜色、明暗分块、水面笔触、树冠结构等），作为绘制的验收标准，见 [art-pipeline.md](art-pipeline.md) 的“原版画法”。
