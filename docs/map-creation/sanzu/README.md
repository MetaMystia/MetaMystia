# 三途川

阅读限制见 [../README.md](../README.md)。

地图 ID `1073742300`（非托管段，无需签名），72×48 格，资源包 `SanzuRiver` v0.2.0。本版完成美术、碰撞、坡度、出生点与相机；不含 NPC、出口、采集与营业。

设定考据与原文摘录见 [lore.md](lore.md)。下文的编号（如 Y1、N2）指向考据里的条目；标为“设计”“推断”的内容不是原作设定。

## 布局依据

- **地理关系**：从妖怪之山背面经中有之道到达三途河，此岸河滩为赛之河原，对岸为彼岸（Y1、Y3）。地图南面入口是中有之道，中部是赛之河原，北面是河与对岸。
- **河**：浓雾、雾中微光、长苔尖石；水流缓慢无声；只能乘死神的船过河，对岸不可到达（Y1、Y2）。水面宽阔，取“像海”的印象（Y10、Y11）。
- **河原**：圆石、卒塔婆、红绿纸风车、积石（Z3、Y14），戎璎花的积石大会（Y6），六地藏（Z3、Z4）。
- **中有之道**：面向死者的摊位，像庙会一样热闹（Y3）。
- **其余**：台地上的衣领树（Z2，设计）、紫花树与无缘塚碑（Y5，设计）；东岸鱼市（N2，设计）；搁浅漏船（N3，推断）。

## 构建与检查

当前版本为生图重绘版（[../paintover.md](../paintover.md)）；程序化版保留，用来出布局底图。

```text
# 程序化版（布局底图来源）
python tools/day-map-art/maps/sanzu/build.py .tmp/day-map/sanzu-proc --font <像素字体.ttf>
python -m maps.sanzu.refine draft .tmp/day-map/sanzu-proc draft.png        # 以下在 tools/day-map-art 下运行

# 生图：按 prompts/ 依次生成成品总图、地面层、物件表；地面层分块细化
python -m maps.sanzu.refine split plate.png win/
python -m maps.sanzu.refine stitch plate.png win/ plate_fine.png 90,130
python -m maps.sanzu.sprites build maps/sanzu/sprites.json <物件表目录> spr/

# 组装（工作目录含 plate_fine.png 与 spr/）
python -m maps.sanzu.assemble <工作目录> <输出目录> --font <像素字体.ttf>

# 1:1 标注图（底图用 render_ref.py 从资源包渲染）
python tools/day-map-art/annotate.py SanzuRiver.zip <1:1 渲染.png> annotated.png --font <像素字体.ttf> --labels tools/day-map-art/maps/sanzu/labels.json
```

- 字体用 Fusion Pixel Font 12px（OFL-1.1）日文版；同作者的 Ark Pixel 12px 缺“賽”“縁”。
- 输出：`SanzuRiver.zip`、`preview.png`（1:1）、`preview_half.png`、`overview.png`、`debug.png`、`report.txt`、各图层缩略图、固定区域裁切。
- 本版离线检查：加载校验通过；5 个出生点连通；坡度格全部在可走区域内；往返渲染与预览一致。未进行游戏内实测。
- 栈桥、拱桥、石阶、码头的位置以 `place.py` 的测量值为准；程序化版的 `layout.py` 只用于出底图。
