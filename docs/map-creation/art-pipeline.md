# 地图绘画流程

阅读限制见 [README.md](README.md)。

本文是程序化绘制的方法：用代码画出完整地图。它也是生图重绘的第一步（出布局底图），见 [paintover.md](paintover.md)。

## 原则

- **可复现**：贴图由脚本绘制或由脚本从生成图组装，提示词与参数都在仓库里。不手工修改导出的 PNG；需要在编辑器里调整时，把调整同步回脚本。
- **不复用游戏资源**：原版只用来测量规格、对比效果，以及作为生图的风格参考图；不把原版贴图放进资源包。
- **先测量，再设计**：尺寸、配色、分层、碰撞画法先从原版读出，见 [research.md](research.md)。
- **构图优先**：先定分区、主路径和焦点，再加细节；细节不能淹没路径。
- **每一步出预览**：每加一层就看总览和固定的一组 1:1 裁切，与原版同类区域并排比较。

## 原版画法

以下是对原版地图的观察，也是绘制的验收标准。

- **视角与光**：3/4 俯视，光从左上来。立体物分“顶面 + 朝镜头的前侧面”两块明暗，顶面亮、前侧面暗，背光一侧再暗一级。
- **平涂色块**：大面积单色，靠 2–4 级色块和少量笔触表现质感；不用连续渐变，不用抖动。
- **描边**：物件 1 像素深色描边，下缘加重；描边色是本体暗部的色相偏移色，不用纯黑。地面材质之间不描线，用深色边、卵石带或草点过渡。
- **色相偏移**：暗部偏冷、偏饱和，亮部偏暖、偏淡。
- **水面**：底色平涂，加稀疏的低对比圆斑、近岸一圈浅水带、少量“~”形 1 像素波纹与高光点；岸线有一圈卵石或 2 像素深色岸影。
- **地面**：泥土底色上撒大量 2–7 像素小圆点，聚成苔草斑块；斑块中心实心，边缘是点。
- **树冠**：多个云团叠成冠，每团下缘一道深色弧线，左上亮、右下暗，外轮廓 1 像素深线；冠底偶有点状暗纹。
- **场景边缘**：用整片树冠、岩壁、雾或深色地形压暗，相机范围内看不到地图外。

## 分层

| 层 | 排序层 / 顺序 | 内容 | 切片 |
|---|---|---|---|
| Ground | `Background` / -2000 | 平铺在地上的一切：水、地面、道路、台地顶面与立面、栈桥、桥面、花草、物件投影、水中倒影 | 1×1 格（48 像素），内容去重 |
| 物件 | `Character`，按 Y 排序 | 人物能绕前绕后的：石块、积石、灯笼、摊位、树、雕像、栏杆 | 每个物件一张精灵，锚点在脚底 |
| Canopy | `Overlay` / 0 | 永远盖在人物上方：边界林、灯笼串、门楣 | 4×4 格大切片，全透明块不导出 |
| Fog | `Overlay` / 10 | 半透明雾、雾中微光 | 同上 |
| Glow | `Overlay` / 20 | 半透明光晕、光束 | 同上 |
| 顶层物件 | `Overlay`，指定顺序 | 需要单独摆放、以后可能做动画的顶层物（人魂、彩旗、门楣） | 单独精灵 |

- 能踩上去的（桥面、栈桥）进 Ground；会挡住人物一部分的进物件或 Overlay。
- 不要把所有物件烘焙进 Ground：烘焙后人物永远压在上面。物件的投影烘焙进 Ground。
- 人物能走进去的建筑拆成前、后两张精灵，分别以前缘、后缘为脚点；不让进的建筑用碰撞挡住整个占地。
- Mod 单图上限 4096 个切片。72×48 格的地面去重后约 3400 片；超出时把地面改为 2×2 格切片（`build.py --chunk 2`）。

## 画布与坐标

- 世界坐标 x 向右、y 向上，1 格 = 48 像素；画布左上角对应 `(x0, y1)`。
- 所有区域、路径、地标在 `layout.py` 里用世界坐标定义（多边形、折线 + 宽度、矩形），绘制、碰撞、坡度共用这一份数据。
- 精灵的 `pivot` 是脚点像素；导出时换算成左下原点的归一化锚点。切片 `rect` 以图片左下角为原点。

## 调色

- 每种材质一组 3–5 级色阶：暗部偏冷偏饱和、亮部偏暖偏淡（`core.shift` 可在 HSV 空间微调），按预览反复调整。
- 全图先定主调，再定少量重点色：重点色只出现在希望玩家注意的地方（地标、入口、交互物）。三途川的主调是灰蓝、青绿与卵石灰，重点色是彼岸花的红、地藏围兜的红、灯火的暖黄。
- 远景降低饱和度与对比，再罩雾层；近景保持原版的饱和度。
- 同一类物件（石头、木头）在全图用同一组色阶，避免拼贴感。

## 材质画法

见 `dayart/materials.py`。

| 材质 | 方法 |
|---|---|
| 平涂斑块 `mottled` | 低频噪声按面积比例量化成 3–4 级 → 众数滤波合并成色块 → 孤立像素并入邻色 |
| 苔草地 `dab_ground` | 泥土底色；覆盖度高处铺实心斑块，斑块外圈与内部撒 2–7 像素圆点 |
| 水面 `water` | 底色平涂 + 稀疏圆斑 + 宽度带噪声的近岸浅水带 + “~”形波纹 + 少量高光；岸下 2 像素深色线 |
| 卵石滩 `pebbles` | 大、中、小三层，各层从上往下画（下面的压住上面的）；每颗三色明暗、下缘描边、底部 1 像素接触阴影；密度场控制疏密，湿度场让近水的石头变暗变冷 |
| 崖面 `boulder_wall` | 顶面遮罩向下平移挤出立面；立面里按行排圆角石块，块间留深缝，顶部长苔，脚下一圈接触阴影 |
| 侧面 | 顶面向右挤出 10–15 像素作背光侧面，朝东的边也能看出高差 |
| 雾带 `fog_bands` | 噪声沿 x 拉长后按纵向密度分级成几档透明度 |

通用技巧：

- 边界用“有符号距离 + 噪声”扰动，再做一次开闭运算去掉单像素毛刺（`core.roughen`、`core.clean`）。
- 量化后做众数滤波是得到平涂色块的关键；滤波核越大，色块越整。
- 散布物体用近似泊松分布（最小间距），避免网格感；散布前从遮罩里扣掉路径、出入口和地标周边。
- 大面积单一材质（如整片卵石滩）要用低频密度场分出疏密，再加少量打断（小路、水洼、砂地、苔斑）。

## 物件画法

见 `dayart/props.py`、`dayart/sprite.py` 与各地图的 `props.py`。

- 用像素坐标原语（矩形、多边形、线、椭圆）拼形，最后统一 `outline()` 描边。
- 立体物分顶面与前侧面；圆形物体在 3/4 视角下压扁，高宽比 0.6–0.8。石块用 2–3 个椭圆拼出不规则轮廓。
- 小物件（花头、风车、人魂）用字符画定义，做几个变体并随机翻转。主色要占大部分像素，否则缩到 1:1 后看不清。
- 树冠用 `canopy()`：云团自上而下叠画，每团左上亮、下缘深弧，越靠下越暗。边界林混用阔叶、杉、柳、枯树，树冠互相重叠成整片。
- 文字用像素字体直接画在精灵上（12 像素字体按 12 像素绘制），字体只用于生成图片，不随资源包分发。缺字时换覆盖更全的字体，不要用方框代替。
- 尺寸以人物约 1 格高为参照：地藏约 0.7 格、石灯笼约 1.5 格、摊位宽约 3.5 格、树 2.5–3.5 格高。

## 雾与光

formatVersion 1 只有普通透明混合，没有加法、乘法材质，用分级透明度的贴图模拟：

- **纵深雾霭**：按世界 y 分 5–6 级透明度（约 0.08–0.5），越远越浓。
- **雾缕**：几块细长扁椭圆拼成一条横向雾带，两级透明度，顶缘 2 像素提亮；稀疏、长短不一，不排成整齐的行。块状噪声做的雾像地面污渍，不要用。
- **通透区**：可走区域和交互物上空的雾压到 0.15 以下。
- **光**：光晕和光束都用三级透明度的硬边形状（中心、半影、外圈），颜色用暖白或灯色，透明度 0.1–0.3。
- 不用连续渐变的透明度：既不符合原版的硬边风格，放大后也会出现色带。

## 切片与打包

见 `dayart/pack.py`。

- Ground 按 1×1 格切片，按内容哈希去重，打进 2048 宽的图集页；每页按实际高度裁掉空白，`rect` 按页高换算成左下原点。
- Overlay 各层用 4×4 格大切片，全透明块不导出。
- 物件每个精灵一个切片；`pivot` 归一化并限制在 0..1。
- 同一地图的切片 key 必须唯一：各层用不同前缀（Ground `g`、Canopy `c`、Fog `f`、Glow `l`、物件 `o_`）。
- BGM 当前必须提供可解码的 `intro`、`loop` WAV（可用同一文件）。`pack.synth_bgm` 只生成占位音，正式发布前替换。
