# 白天联机角色可见性

两名玩家进入白天。用玩家面板核对地图和坐标，用场景角色集合及角色下的名牌核对实体。公共大厅和同房间均适用。

| 操作 | 期望 |
|---|---|
| 在同一地图相遇，随后一方离开地图并移动 | 同图时双方各看到一个对端角色；异图后角色与名牌消失，面板仍更新对方地图与坐标。 |
| 对方在异图停止发送移动，本机切入其地图 | 换图完成时按最后一次坐标创建角色与名牌，碰撞体启用。来回切图后每个 UID 只对应一个实体。 |
| 对方离开后换肤，再回到本机地图 | 在窗口中保留玩家资料；重新出现时使用最新皮肤、位置和名牌。 |
| 对方在异图断开并重连 | 旧 UID 从名册和场景移除，新 UID 在同图时出现。 |
| 两端同房进入营业 | 双方各有一个同房角色，继续应用营业移动。 |
